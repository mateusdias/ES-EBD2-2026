## Artigo: The entity-relationship model—toward a unified view of data

Esse paper impressionante, foi escrito no final da década de 70. O artigo é um resumo da tese de doutorado do Prof. Chen. Nele, é possível entender a proposta do que é um Modelo Entidade-Relacionamento (MER) proposto pelo próprio professor. 

Mas por quê o professor Mateus colocou essa referência nesse repositório de Banco de Dados 2 (onde o foco são bancos não relacionais)? Por uma simples razão: o trabalho de compreender seus dados e a composição de entidades como foi antigamente proposto, se adaptados, podem servir perfeitamente para os projetos de bancos modernos. Inclusive, em muitos casos é necessário conhecer profundamente a modelagem relacional para construir ou migrar projetos legados para novos formatos e, pos isso, é sempre válido relembrar.

Décadas se passaram após sua publicação, mas até hoje faz total sentido este artigo. Mesmo com os bancos mais modernos da atualidade, os conceitos de entidades, dados e a forma como estruturar atributos, ainda é bastante interessante. Com poucas adaptações é possível pensar na arquitetura dos dados em ambientes modernos. 

Uma curiosidade notável é: O Prof. Chen publicou poucos artigos e não teria, por exemplo um currículo de pesquisador cheio de papers. Mas, seus poucos trabalhos (em termos de quantidade), trouxeram contribuições imensuráveis para a Computação em termos de qualidade. 

Uma cópia foi colocada neste diretório do repositório para facilitar sempre seu acesso (arquivo: paper-professor-chen.pdf)
